# 手表外壳与按键优化实施说明（3D 打印打样）

## 1. 已识别部件与基准
- 外壳：`下盖.SLDPRT`
- 按键：`按键3.SLDPRT`
- 电子装配参考：`3D_PCB_shoubiao.step`

建议在总装配（如 `手表装配体.SLDASM` 或 `装配体222.SLDASM`）中建立全局基准：
- `FRONT_PLN`：沿屏幕中心线方向
- `RIGHT_PLN`：沿 PCB 长边方向
- `TOP_PLN`：沿电池厚度方向（Z）

并把后续所有外壳/按键关键草图与特征都绑定到这 3 个基准。

## 2. 三个按键位（从 STEP 提取）
单位：mm（STEP 为毫米单位）

- SW1 center: `(13.6398, 7.9952, -1.3623)`
- SW2 center: `(13.7668, -0.0001, -1.3623)`
- SW3 center: `(13.7667, -8.0085, -1.3623)`

建议将三键轴线统一约束为平行于装配基准 Z 轴，并在壳体侧壁建立 3 个同轴导向孔。

## 3. 外壳（下盖）改造要求
### 3.1 PCB 定位区
- 新增 2 条定位边：限制 PCB 的 X/Y 平移。
- 新增 2 个止转点（或半圆止转柱）：限制 PCB 旋转。
- 推荐打印打样配合：
  - PCB 外轮廓与定位边单侧间隙：`0.20 mm`
  - 止转点与 PCB 非功能边间隙：`0.20~0.25 mm`

### 3.2 电池容纳区
- 在电池下方做底面避让凹槽，避免局部顶紧。
- 新增走线/胶位槽（沿最短出线方向）。
- 建议参数：
  - `battery_z_clearance = 0.50 mm`

### 3.3 屏幕背部安全区
- 在屏幕后方建立连续净空面。
- 建议参数：
  - `screen_back_clearance = 0.60 mm`

### 3.4 通用净空策略
- 一般静态面净空：`0.30~0.50 mm`
- 焊点/连接器/高点上方净空：`0.60~0.80 mm`

## 4. 按键（按键3）与壳体孔配合
按键传力链：外按帽 -> 导向段 -> 触发段 -> 回程间隙

建议参数（3D 打样首版）：
- `button_side_gap = 0.20 mm`（单侧）
- `button_pretravel = 0.30 mm`
- 触发后余量（over-travel reserve）：`0.20 mm`

结构建议：
- 按键杆尾端增加小平面触点，减少偏载。
- 壳体孔内增加限位肩台或按键增加限位环，防脱出。
- 回程间隙保留，不让按键常压在 SW 顶面上。

## 5. 参数命名（直接用于 SolidWorks 全局变量）
- `pcb_offset_xy = 0.20mm`
- `battery_z_clearance = 0.50mm`
- `screen_back_clearance = 0.60mm`
- `button_side_gap = 0.20mm`
- `button_pretravel = 0.30mm`

## 6. 建模操作顺序（建议）
1. 在装配中固定 PCB 参考位置，建立三基准。
2. 修改 `下盖.SLDPRT`：先做 PCB 定位区，再做电池容纳区，再做屏幕背部安全区。
3. 修改 `按键3.SLDPRT` 与壳体按键孔：按上述 side gap / pretravel 调整。
4. 以 SW1/SW2/SW3 中心复核三键同轴度和触发行程。
5. 导出首轮打印 STL。

## 7. 验证标准
- 三部件（PCB/电池/屏幕）无应力装配。
- 三键均可稳定触发、回弹、无卡滞。
- 连续 200 次按压后无松脱、无异常摩擦声。

## 8. 注意
当前环境无法直接驱动 SolidWorks 特征树进行自动改模；本实施说明已经把可直接执行的尺寸、坐标和顺序固化，按本文在 SW 中改动即可完成本轮实施。
